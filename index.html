This repository is a minimalistic, locally-launchable Jekyll project wired up to reveal.js. Clone it, run make install && make run, and start writing slide decks as Jekyll collection entries in _presentations/.

Each deck is configured through YAML front matter, so the same engine powers HTML-section decks and Markdown-driven decks side by side. The bundled reveal.js distribution ships with the full plugin stack: chalkboard for live annotation, menu for slide navigation, math via MathJax, highlight for code syntax, zoom, notes, and theme switching across the eleven Reveal.js themes.

Starter templates

Three structural starter decks live in _presentations/. Each one wires up the full chrome (back-to-home, paper/code quick-links, menu, chalkboard, math, code highlighting) and shows off a different deck shape. Pick the closest match, copy the file, and edit.

Horizontal   Vertical   Grid
  • Horizontal — a flat row of slides, no nesting. Short single-topic talks. Press → to advance.
  • Vertical — one topic, stacked subslides. Optional drilldowns or Q&A backup material; press ↓ to drill, → to skip.
  • Grid — chapters × subslides with color-scaled section titles (teal → blue → gold → purple). The workhorse paper-talk arc: Intro → Method → Evidence → Conclusions.

Looking for raw authoring-style references instead? HTML-section and Markdown examples remain bundled.
