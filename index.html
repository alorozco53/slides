This repository is a minimalistic, locally-launchable Jekyll project wired up to reveal.js. Clone it, run make install && make run, and start writing slide decks as Jekyll collection entries in _presentations/.

Each deck is configured through YAML front matter, so the same engine powers HTML-section decks and Markdown-driven decks side by side. The bundled reveal.js distribution ships with the full plugin stack: chalkboard for live annotation, menu for slide navigation, math via MathJax, highlight for code syntax, zoom, notes, and theme switching across the eleven Reveal.js themes.

The two example decks below illustrate both authoring styles. Use them as starting points and replace with your own content.
